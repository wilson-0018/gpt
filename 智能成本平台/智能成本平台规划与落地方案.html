智能成本平台规划架构与落地方案

一、平台定位与业务全景

01

平台定位与建设目标

成本数据从哪里来

汇集报价、成交、材料行情、研发规格与历史配置，说明来源、条件和时间。

每颗料的成本可解释

按材料、二级料、用量、工艺和费用拆解，说明模型如何建、结果怎么算。

成本应用可以闭环

测算用于报价核价，结果进入项目和采购决策，后续跟踪目标与降本。

平台目标：把有来源的成本数据沉淀为可解释的物料成本模型，用于报价、整机竞争力判断和量产降本管理。

平台重点回答四个业务问题

业务重点平台要给出的答案
① 合理成本怎么算，模型怎么建？按品类建立材料、二级料和工艺模型，给出单颗物料成本、关键参数及偏差原因。
② 内部如何对比和判断报价？采购内部对供应商不同轮次报价、历史可比价和模型测算价进行对比，定位不合理项，支撑核价与议价。
③ 新品/芯片BOM和整机成本是否可控、有竞争力？对接BOM核价工具，拆出器件贡献、整机成本和阶段变化，判断目标是否超出、配置和价格是否有优化空间。
④ 量产物料的成本目标和降本计划如何推进？分解料号目标，识别材料传导与价格差距，形成负责人、动作、期限和结果跟踪。
阶段六项核心能力中的交付扩展说明
一期成本模型核价、定商对标与基线、量产成本管理。成本库、测算和报价对比为共用基础；量产任务可先不依赖目标价。
二期新品AI拆解、目标价管理、整机全周期成本。技术降本、阶梯价、竞品、份额/TCO及其他BOM相关分析为扩展，不替代六个核心模块。

平台总体架构与系统关系

各平台定位与系统边界

二、核心功能域架构

04

核心功能域与成本模型架构

这一层回答“业务怎么计算”，是成本模型与规则的逻辑架构。数据架构说明这些输入和结果如何组织；技术架构说明用什么服务和组件执行。同一物料模型被报价核价、二期整机成本和量产降本共同调用。

05

数据架构：来源、结构与结果关联

数据围绕“价格—物料结构—模型参数—核价结果”组织。每条价格说清来源和适用条件，每个结果能查到所用模型和输入；版本、审批、审计作为基础支撑实现，不占业务交付重点。

数据域关键内容使用关系
物料与技术结构料号、品类、规格、二级料、用量、BOM、工艺连接研发输入、模型要素和报价明细。
价格与条件来源、供应商、单价、单位、税币、有效期、MOQ/账期等按用途选价，先判断是否可比。
模型与配置公式、历史参数、费率、良率、利用率、适用范围一期成本核价复用；二期支持AI初版与成本传导。
项目与结果核价明细、报价轮次、差异原因、项目引用；二期目标和趋势将计算结果落到采购和项目动作。
06

技术架构：承载数据、计算与业务协同

实现重点一期做法
前后端沿用既有React/TypeScript、Java/Spring Boot与关系数据库方向，由IT确认企业支持版本。
公式与金额使用受限公式、统一单位与十进制金额；计算口径先与人工标准样例对齐。
系统连接按来源建立适配器；先明确字段、Owner与对账样例，再逐步联调；SCP接口口径待确认。
AI与权限AI按授权读取资料、输出待确认结果；关键成本参数由资源商务/采购确认。
07

核心计算规则与业务校验

计算环节一期主要规则二期复用
材料与二级料净用量×单价÷利用率；用量已含损耗时不重复加损耗；模组与展开子件不重复计价。整机汇总、原料变动传导。
加工与费用按工序、节拍、设备和工时定义费用；明确加工费是否已含人工、折旧和能耗。新品方案比较、技术变更成本。
成本区间与报价差距区间来自已确认的参数情景；GAP=(可比报价−模型基准)/模型基准；基准缺失或为零不计算。目标可行性、整机竞争力和降本空间判断。
可比条件同规格、单位、税币、有效期和采购条件，保留差异说明。趋势分析区分价格变化与配置变化。

问题处理：缺价不算零；过低报价要检查漏报和条件差异；成本模型不适用时转人工复核，不能用一个统一误差目标覆盖所有品类。

08

AI与测算、预警的分工

环节实现边界
用户输入接收研发资料、变更方案或价格条款，保留来源与适用范围。
AI理解提取参数、识别变更、匹配历史模型，标记缺项和不确定内容。
规则测算公式引擎计算成本和额度；阶梯规则引擎确定应执行价，按订单事件或约定扫描周期监控。
人工与闭环确认输入、规则和实施方案；预警交给采购处理，结果回流后关闭。

三、应用子方案与落地

09

业务功能全景与应用子方案

六项核心业务能力以第三节原业务架构图为准，不因分期调整而增减或重排。以下按原图六项能力展开，先做成本模型核价、定商对标与基线、量产成本管理；技术降本和阶梯价等单列扩展。

9.1　新品AI拆解　｜　二期

研发资料与历史配置结合，快速形成待确认的成本模型初版。

输入 / 输出内容
输入用户上传或IPM提供的需求规格、图纸；历史品类模板、成本配置和参数。
输出模型初版、参数来源、缺项与差异清单；确认后进入正式成本核价。
处理步骤业务与计算规则
AI理解与匹配提取规格、材料和工艺，推荐相似历史模型；每个关键参数保留原文或历史来源。
生成初版AI编排已批准模板与计算工具；缺失的新工艺/费率列为待补，不生成无依据金额。
人工确认NPM采购/研发澄清技术输入，资源商务/采购修改并确认模型；AI草稿不直接发布。

9.2　成本模型核价　｜　一期

集中价源和物料结构，形成可解释的单颗物料成本。

输入 / 输出内容
输入料号、规格、材料/二级料价、用量、工艺、费用及历史参数；保留来源与计价条件。
输出物料成本模型、成本卡、合理区间、关键参数与差异依据。
处理步骤业务与计算规则
统一数据按料号、规格和用途整理价源，统一单位、币税与有效期；缺价不补零。
建立模型按品类拆材料、二级料、工序和费用；用量已含损耗不再重复计入，模组/子件不重复汇总。
校核使用资源商务/采购以人工标准样例验证后用于测算，采购运营/IT维护取数与运行。

9.3　定商对标与基线　｜　一期

在采购内部比较报价、历史价和模型价，定位差异，支撑议价。

输入 / 输出内容
输入项目、料号、规格、多家多轮报价、商务条件、模型价与历史可比价。
输出分项报价对照、超差与澄清清单、核价结论和采购动作。
处理步骤业务与计算规则
对齐口径对齐规格、单位、税币、用量和报价条件；未映射项标明待核实。
计算差距差距率=(可比报价−比较基准)/比较基准；缺基准或基准为零不计算；低价同样查漏报。
确认成本基线资源商务/采购确认核价依据、议价结论和成本基线，经授权签批后供SRM定商引用；报价或模型发生实质变化需重新确认。

9.4　目标价管理　｜　二期

管理业财维护的编码级/部分规格级物料目标，以及NPM项目整机目标；目标引用与预警不替代量产成本任务模块。

输入 / 输出内容
输入业财维护的编码级物料目标及部分规格级目标（电池、内存等）；报价、项目整机目标、NPM BOM结果和实际执行量。
输出竞价/RFI规格目标对照、RFQ编码目标差距与预警、项目整机达成。
处理步骤业务与计算规则
分场景引用竞价/RFI按规格型号带出；量产RFQ按物料编码引用；项目整机目标结合NPM BOM核价管理。
对比预警统一口径后比较报价与目标，阈值由业务配置；规格与编码映射未确认、缺目标或目标为零时提示待核验。
结果闭环业财维护物料目标，资源商务/采购处理RFI/RFQ目标偏差；NPM采购/研发结合BOM核价跟踪项目整机目标。

9.5　量产成本管理　｜　一期

基于现行物料价、材料行情和成本模型，识别量产差距，形成采购任务并核对结果；不依赖二期目标价管理才能运行。

输入 / 输出内容
输入现行物料价格、原材料/二级料行情、器件成本模型、合同传导规则、计划与实际采购量。
输出材料传导与价差清单、议价/调价任务、价格生效跟踪、已签及实际降本结果。
处理步骤业务与计算规则
识别与测算行情变化触发模型重算，区分材料、工艺、汇率和商务影响，剔除已传导部分。
采购任务资源商务/采购确认差距、责任人和期限，推进议价；新价格由SRM流程执行。
结果核对按可比基准与实际采购量核算，区分机会、已签和实际兑现；业财确认结果，防止重复计算。

9.6　整机全周期成本　｜　二期

结合NPM BOM核价管理整机成本、目标达成、横评和器件趋势。

输入 / 输出内容
输入BOM工具的项目/机型、阶段、版本、用量和核价结果；器件成本、项目整机目标与参考配置。
输出NPM整机核价、目标差额、器件贡献、整机/器件趋势和成本竞争力清单。
处理步骤业务与计算规则
BOM对账保留原工具结果，对齐料号、用量、币税和合计；模组与展开子件不能重复计价。
目标与横评按项目/机型比较整机目标；横评先解释规格差异，不以物料目标简单相加替代整机目标。
变化管理区分单价与BOM配置变化、历史与预测；NPM采购/研发确认项目动作，资源商务确认器件成本。

9.7　技术降本（ECN/DCN）　｜　二期扩展

用户输入变更方案，AI辅助生成成本测算和降本额度，确认后跟踪切换效果。

输入 / 输出内容
输入用户输入/上传变更前后BOM、规格/图纸、用量与工艺差异；旧/新价、预计替代量、验证/模具费、库存与在途处置。
输出变更前后成本对比、单位节省、预计净降本额度、盈亏平衡量、假设/缺项清单和技术降本任务。
处理步骤业务与计算规则
AI解析变更识别ECN/DCN变更点，匹配历史模型、价源与参数；用户仅有描述时先形成待确认的结构化方案。
自动调用测算单位节省=原方案成本−新方案成本；预计净降本=单位节省×实际可替代的预计数量−一次性增量成本。AI调用公式工具计算，不自行编造价格。
确认并跟踪研发确认可行性与适用范围；资源商务/采购确认价格和切换方案，业财核对费用；引用IPM批准的变更，按实际替代量更新兑现。

9.8　阶梯价测算与监控　｜　二期扩展

按约定阶梯自动测算降本额度，核对订单应执行价并及时预警。

输入 / 输出内容
输入物料/供应商、基准价、合同/报价阶梯、数量门槛、计量单位、有效期与计量周期；订单/收货/退货数据及执行单价。
输出各档降本测算、适用阶梯与应执行价、订单价差/超付风险、预警任务及闭环结果。
处理步骤业务与计算规则
识别阶梯规则明确单笔/累计周期、按订单或收货量计量、达到门槛后仅后续执行或追溯全量、阶梯分段计价等条款；规则经采购确认。
测算应执行价按已确认规则取数量与适用单价；预计额度=基准情景金额−阶梯情景金额，分段规则逐段汇总；预计订单量与实际执行量分开。
订单监控闭环逐行比较订单价与适用阶梯价，超容差自动预警；接近门槛/到期按需提醒。采购处理改价或追溯，业财确认补差；无规则不误报。
其他二期扩展用途
竞品成本拆解整理同档机型配置和成本估算，支撑横评；估算与采购事实分开。
归因 / 份额 / TCO按业务需要复用成本模型和价源，复杂返利与合同口径确认后再实施。

子方案协作与业务验收

交接关系上游交付下游如何使用
成本库 → 模型测算价格、条件、物料结构与费用配置。计算物料成本，解释每项来源。
模型 → 报价核价成本卡、合理区间、关键假设。与可比报价逐项对比，形成采购动作。
二期新品AI → 模型初版模型、历史匹配依据、缺项。人工确认后纳入统一模型。
模型 / BOM工具 → 整机成本器件成本、BOM、工具结果、项目范围。汇总、横评、画趋势，判断成本竞争力。
模型 / 行情 / 规划 → 量产降本目标、传导差额、合同条件与用量。生成计划与任务，跟踪执行结果。
阶段真实业务验收要看到的结果
一期物料模型、多轮报价对标与基线、一个量产价差/调价任务。模型可解释、基线可用、量产任务从机会走到新价与结果核对。
二期一个新品初版模型、一个NPM项目和一个量产降本周期。输入规格可澄清，BOM结果可对账，目标与计划可推进，结果可核对。
运营一次源数据异常与一次访问/接口问题。采购运营/IT能找到责任人、处理问题并恢复使用。

四、分期实施与保障

11

6—8个月分期实施计划

一期先做成本库、模型、测算和内部报价核价；二期再做目标与降本、新品AI、整机全周期成本。6—8个月内完成核心试点，技术降本等扩展按数据与资源成熟度选择，不要求全部同步上线。

阶段交付重点业务关口
M1｜一期准备确定三项一期能力、价源、品类Owner、模型样例、报价和量产场景。明确核价、基线与量产结果口径。
M2｜模型与核价成本库、模型参数、成本测算与报价对比。人工标准样例和报价差距核对通过。
M3｜基线与量产试点定商对标与基线确认；材料传导、量产价差和调价任务。采购可使用核价依据；量产任务有责任人与动作。
M4｜一期验收三项能力试点闭环，核对新价执行及量产结果。成本可解释、对标可用、量产任务有结果。
M5—M6｜二期核心新品AI拆解、业财物料目标、项目整机目标与NPM全周期成本。六项核心框架保持不变，验证二期真实任务。
M7—M8｜二期推广与扩展完善目标引用和整机趋势；技术降本、阶梯价等扩展按需试点。业务验收、品类推广与运营移交。

实施保障与待确认事项

关键保障责任与动作
业务专家投入资源商务/采购按品类固定评审模型、样本与报价；NPM采购/研发按任务澄清规格和BOM。
产品与研发产品负责场景、字段和验收，IT按一期/二期实施；团队配置与工期在启动时确认。
运营与协同采购运营/IT统一组织培训、数据问题、接口运行和访问管理。
目标与经营口径二期由降本规划Owner/业财确认目标、计划量、基准与实际结果计算。
接口边界SRM、IPM、TIM、BOM工具与现有价源各有Owner；SCP职责与字段方向必须先核实。

重点问题：模型样本不足、规格和价格口径不一致、接口范围不清、业务专家时间不足，会直接影响工期；先缩小试点范围并明确责任，不用“功能已开发”代替业务验收。
