# Guitar Lab · 个人摇滚吉他练习室

手机优先的静态练琴网页，位于本仓库 `guitar-lab/` 目录。

## 功能
- 首月四组曲目：Wish You Were Here、Walk of Life、Sweet Child O' Mine、Beyond 旧曲精修
- B站教学与原谱搜索链接
- 原创练习用简谱 + 六线谱（不是歌曲完整原谱）
- 特殊和弦指板图、技巧符号说明
- 40–200 BPM 节拍器、计时、笔记、本地打卡、JSON 记录导出

## 在线发布
仓库目前是 **private**。GitHub Pages 对私有仓库的支持取决于 GitHub 账户套餐；请先检查仓库 Settings → Pages 是否允许启用。

如允许：
1. Settings → Pages → Build and deployment
2. Source 选择 Deploy from a branch
3. Branch 选择 main，目录选择 /(root)，保存
4. 站点根地址通常为 https://wilson-0018.github.io/gpt/ ，应用入口为 https://wilson-0018.github.io/gpt/guitar-lab/

如果 Pages 不支持私有仓库，可考虑改用单独的公开仓库（**仅发布无隐私数据的静态页面**）或其他静态托管服务。不要为了发布网页直接公开包含其他私人文件的整个 gpt 仓库。

## 注意
- 教学视频和原谱是外链，可能随平台变更。
- 简谱、TAB 是原创技巧示例，并非原曲完整转录。
- 练习数据仅存于当前浏览器本地，清除浏览器数据可能丢失，请定期导出。
